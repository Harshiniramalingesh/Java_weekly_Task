Maven Project Structure
Maven projects follow a standard directory layout to organize source code, resources, tests, and build outputs.

Main directories:
src/main/java – contains the main application source code.
src/main/resources – contains configuration files and resources used by the application.
src/test/java – contains test source code.
src/test/resources – contains resources used for testing.
target – contains compiled classes, packaged files, and build output generated by Maven.
pom.xml – the central configuration file that defines project settings and dependencies.
This standardized structure improves project organization and collaboration.

POM.xml (Project Object Model)
Apache Maven uses a file called pom.xml to manage project configuration.
POM stands for Project Object Model and contains all information required to build the project.

It includes:
Project identification details
Build configuration
Dependency management
Plugin configuration
Java version and compiler settings
The pom.xml file controls how the project is built, tested, and packaged.

Dependencies
Dependencies are external libraries required by a project to provide additional functionality.
In Maven, dependencies are declared in the pom.xml file. Maven automatically downloads them from the central repository and adds them to the project classpath.

Benefits of dependencies:
Avoids manual download of libraries
Simplifies library management
Ensures correct version usage
Improves project maintainability
Dependencies are stored in the local Maven repository on the developer’s system.

JSON

JSON stands for JavaScript Object Notation.
It is a lightweight data interchange format used to store and transfer data between systems.
Characteristics:
Human-readable format
Uses key-value structure
Language independent
Lightweight compared to XML
Widely used in web services and APIs
JSON is commonly used for communication between client and server applications.

Gson
Gson is a Java library developed by Google for processing JSON data.

Main uses:
Converting Java objects into JSON format
Converting JSON data into Java objects

Features:
Simple API
Lightweight library
Easy integration with Java applications
Supports serialization and deserialization

Jackson
Jackson is a popular library used for processing JSON in Java applications.

Main capabilities:
Converting Java objects to JSON
Converting JSON data to Java objects
Handling complex JSON structures

Features:
High performance JSON processing
Supports streaming API
Annotation-based configuration
Widely used in enterprise applications and frameworks.

Maven Lifecycles
A lifecycle in Maven is a sequence of phases used to build and manage a project.
Maven defines three main lifecycles.

Clean Lifecycle
Responsible for removing files generated by previous builds.
It ensures that the project starts with a clean state before a new build process.

Default Lifecycle
Handles the main build process of the application including validation, compilation, testing, packaging, installation, and deployment.

Site Lifecycle
Used for generating project documentation and reports.
